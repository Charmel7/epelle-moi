# ÉPELLE-MOI - Console de Régie

Application Flutter Desktop pour la gestion de concours d'épellation.

##  Fonctionnalités
- Gestion des candidats et des phases du concours
- Chargement de mots depuis fichiers CSV
- Interface dual-screen (Admin + Projection)
- Chronomètre intégré et gestion des scores minimale
